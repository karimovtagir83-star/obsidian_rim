# Задачи — Строки и массивы

> [!abstract] Коротко
> 40 задач на то, что чаще всего просят написать руками на собеседовании и на live coding: разбор и преобразование строк, сравнение с учётом культуры и регистра, форматирование, операции над массивами и классические алгоритмы (два указателя, скользящее окно, частотный словарь). Решения свёрнуты — сначала своя попытка, потом сверка. Теория — в заметках [[Строки и работа с текстом]] и [[Синтаксис и структура программы]].

> [!tip] Правила
> - Пиши и **запускай** код, а не читай решения.
> - После решения задай себе три вопроса: какая сложность по времени, какая по памяти, что будет на пустом или `null`-входе.
> - Задачи «что выведет» решай до запуска.
> - Библиотечные методы использовать можно, но в задачах с пометкой «вручную» — нельзя: смысл в понимании механики.

## 1. Строки: основы

### 1.1. Развернуть строку
Разверни строку задом наперёд. Что будет с эмодзи?

> [!success]- Решение
> ```csharp
> static string Reverse(string s)
> {
>     var chars = s.ToCharArray();
>     Array.Reverse(chars);
>     return new string(chars);
> }
> ```
> Работает для BMP-символов. Эмодзи и другие символы вне BMP кодируются суррогатной парой из двух `char`, и разворот их разрушит. Корректный вариант — по текстовым элементам:
> ```csharp
> static string ReverseSafe(string s)
> {
>     var elements = new List<string>();
>     var e = System.Globalization.StringInfo.GetTextElementEnumerator(s);
>     while (e.MoveNext()) elements.Add((string)e.Current);
>     elements.Reverse();
>     return string.Concat(elements);
> }
> ```

### 1.2. Палиндром
Проверь, является ли строка палиндромом, игнорируя регистр и небуквенные символы.

> [!success]- Решение
> ```csharp
> static bool IsPalindrome(string s)
> {
>     int i = 0, j = s.Length - 1;
>     while (i < j)
>     {
>         while (i < j && !char.IsLetterOrDigit(s[i])) i++;
>         while (i < j && !char.IsLetterOrDigit(s[j])) j--;
>         if (char.ToUpperInvariant(s[i]) != char.ToUpperInvariant(s[j])) return false;
>         i++; j--;
>     }
>     return true;
> }
> ```
> Два указателя навстречу: `O(n)` времени, `O(1)` памяти — без создания очищенной копии строки.

### 1.3. Подсчёт слов
Посчитай количество слов в строке, устойчиво к нескольким пробелам подряд.

> [!success]- Решение
> ```csharp
> static int WordCount(string s)
>     => s.Split((char[]?)null, StringSplitOptions.RemoveEmptyEntries).Length;
> ```
> `Split` с `null` разделяет по любым пробельным символам. Для больших текстов без аллокаций — проход по `ReadOnlySpan<char>` со счётчиком переходов «пробел → не пробел».

### 1.4. Первое неповторяющееся
Найди первый символ, встречающийся в строке ровно один раз.

> [!success]- Решение
> ```csharp
> static char? FirstUnique(string s)
> {
>     var counts = new Dictionary<char, int>();
>     foreach (var c in s) counts[c] = counts.GetValueOrDefault(c) + 1;
>     foreach (var c in s) if (counts[c] == 1) return c;
>     return null;
> }
> ```
> Два прохода, `O(n)`. Наивный вариант с `s.IndexOf(c) == s.LastIndexOf(c)` даёт `O(n²)`.

### 1.5. Анаграммы
Проверь, являются ли две строки анаграммами.

> [!success]- Решение
> ```csharp
> static bool AreAnagrams(string a, string b)
> {
>     if (a.Length != b.Length) return false;
>     var counts = new Dictionary<char, int>();
>     foreach (var c in a) counts[c] = counts.GetValueOrDefault(c) + 1;
>     foreach (var c in b)
>     {
>         if (!counts.TryGetValue(c, out var n) || n == 0) return false;
>         counts[c] = n - 1;
>     }
>     return true;
> }
> ```
> `O(n)` против `O(n log n)` у варианта с сортировкой обеих строк.

### 1.6. Сжатие строки
Преврати `"aaabbc"` в `"a3b2c1"`, но верни исходную строку, если сжатая не короче.

> [!success]- Решение
> ```csharp
> static string Compress(string s)
> {
>     if (s.Length == 0) return s;
>     var sb = new System.Text.StringBuilder(s.Length);
>     int count = 1;
>     for (int i = 1; i <= s.Length; i++)
>     {
>         if (i < s.Length && s[i] == s[i - 1]) { count++; continue; }
>         sb.Append(s[i - 1]).Append(count);
>         count = 1;
>     }
>     return sb.Length < s.Length ? sb.ToString() : s;
> }
> ```
> `StringBuilder` с заданной ёмкостью: конкатенация в цикле дала бы `O(n²)`.

### 1.7. Заголовочный регистр
Приведи каждое слово к виду «Слово».

> [!success]- Решение
> ```csharp
> static string ToTitle(string s) => string.Join(' ',
>     s.Split(' ', StringSplitOptions.RemoveEmptyEntries)
>      .Select(w => char.ToUpperInvariant(w[0]) + w[1..].ToLowerInvariant()));
> ```
> Готовый `TextInfo.ToTitleCase` есть, но он культурозависим и не трогает слова в верхнем регистре целиком.

### 1.8. Обрезать безопасно
Обрежь строку до N символов, не разрезав суррогатную пару.

> [!success]- Решение
> ```csharp
> static string Truncate(string s, int max)
> {
>     if (s.Length <= max) return s;
>     int end = max;
>     if (char.IsHighSurrogate(s[end - 1])) end--;
>     return s[..end];
> }
> ```
> Иначе на конце окажется «половина» символа, который в UTF-8 превратится в U+FFFD.

## 2. Строки: поиск, сравнение, разбор

### 2.1. Сравнение без учёта регистра
Как правильно сравнить логин с «admin»?

> [!success]- Решение
> ```csharp
> string.Equals(login, "admin", StringComparison.OrdinalIgnoreCase)
> ```
> `login.ToLower() == "admin"` создаёт лишнюю строку и ломается в турецкой культуре, где `'I'.ToLower()` даёт `'ı'`.

### 2.2. Умолчания методов
Какие из этих методов культурозависимы по умолчанию: `Contains`, `IndexOf(string)`, `StartsWith`, `Replace`, `==`?

> [!success]- Решение
> Культурозависимы `IndexOf(string)`, `StartsWith`, `EndsWith`, `CompareTo`. Ординальны `Contains`, `Replace`, `==` и все перегрузки с `char`. Именно поэтому `StringComparison` указывают явно везде.

### 2.3. Разбор «ключ=значение»
Разбери строку на ключ и значение, обрезав пробелы, без лишних аллокаций.

> [!success]- Решение
> ```csharp
> static bool TryParse(ReadOnlySpan<char> line, out ReadOnlySpan<char> key, out ReadOnlySpan<char> value)
> {
>     int sep = line.IndexOf('=');
>     if (sep <= 0) { key = value = default; return false; }
>     key = line[..sep].Trim();
>     value = line[(sep + 1)..].Trim();
>     return true;
> }
> ```
> У `ReadOnlySpan<char>` есть `IndexOf` и `Trim`, не создающие строк.

### 2.4. Разбить CSV-строку
Разбей `"a, b,, c "` на непустые обрезанные элементы.

> [!success]- Решение
> ```csharp
> var parts = input.Split(',', StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries);
> ```
> `TrimEntries` доступен с .NET 5. Для настоящего CSV с кавычками и переводами строк нужен полноценный парсер, а не `Split`.

### 2.5. Подсчёт вхождений подстроки
Посчитай, сколько раз подстрока встречается в тексте (с перекрытиями и без).

> [!success]- Решение
> ```csharp
> static int Count(string text, string pattern, bool overlapping = false)
> {
>     int count = 0, index = 0;
>     while ((index = text.IndexOf(pattern, index, StringComparison.Ordinal)) >= 0)
>     {
>         count++;
>         index += overlapping ? 1 : pattern.Length;
>     }
>     return count;
> }
> ```
> Обязателен `StringComparison.Ordinal`: культурное сравнение и медленнее, и может «находить» иначе.

### 2.6. Проверка префикса пути
Проверь, что нормализованный путь лежит внутри корневого каталога.

> [!success]- Решение
> ```csharp
> var root = Path.GetFullPath(rootDir);
> var full = Path.GetFullPath(Path.Combine(root, userInput));
> bool inside = full.StartsWith(root + Path.DirectorySeparatorChar, StringComparison.Ordinal);
> ```
> Без нормализации `../../etc/passwd` выходит за пределы каталога — классическая уязвимость обхода пути.

### 2.7. Маскирование
Замаскируй номер карты, оставив последние 4 цифры.

> [!success]- Решение
> ```csharp
> static string Mask(string card) => card.Length <= 4
>     ? card
>     : new string('*', card.Length - 4) + card[^4..];
> ```
> `card[^4..]` — срез последних четырёх символов.

### 2.8. Сравнение с сортировкой
Отсортируй список имён для интерфейса и для машинного вывода. В чём разница?

> [!success]- Решение
> ```csharp
> var forUi = names.OrderBy(n => n, StringComparer.CurrentCulture).ToList();
> var forApi = names.OrderBy(n => n, StringComparer.Ordinal).ToList();
> ```
> Культурная сортировка учитывает правила языка (и зависит от локали сервера), ординальная стабильна и одинакова везде — её и используют для машинных данных.

## 3. Форматирование и культура

### 3.1. Формат денег
Выведи 1234.5 как «1 234,50 UZS».

> [!success]- Решение
> ```csharp
> Console.WriteLine($"{1234.5m:N2} UZS");
> ```
> `N2` — с разделителями групп и двумя знаками; разделители зависят от культуры.

### 3.2. Дата для машины и для человека
Отформатируй `DateTimeOffset` для JSON и для интерфейса.

> [!success]- Решение
> ```csharp
> var now = DateTimeOffset.UtcNow;
> Console.WriteLine(now.ToString("O"));                                    // 2026-08-13T10:15:30.1234567+00:00
> Console.WriteLine(now.ToString("dd.MM.yyyy HH:mm", new CultureInfo("ru-RU")));
> ```
> `"O"` — round-trip формат ISO 8601, единственный правильный для обмена данными.

### 3.3. Проценты и выравнивание
Выведи таблицу из двух колонок: название слева на 20 символов, процент справа с одним знаком.

> [!success]- Решение
> ```csharp
> Console.WriteLine($"{name,-20}{share,8:P1}");
> ```
> Отрицательное число — выравнивание влево, положительное — вправо.

### 3.4. Инвариантная культура
Почему в CSV нужно писать числа через `InvariantCulture`?

> [!success]- Решение
> Иначе на русской локали разделителем станет запятая, которая совпадёт с разделителем полей CSV, и файл перестанет разбираться. Машинные форматы — всегда инвариантная культура.

### 3.5. Интерполяция и логи
Почему `logger.LogInformation($"Заказ {id}")` — ошибка?

> [!success]- Решение
> Строка форматируется всегда, даже при отключённом уровне, и теряются структурные поля. Правильно: `logger.LogInformation("Заказ {OrderId}", id)`.

### 3.6. Числа в hex и binary
Выведи 255 в шестнадцатеричном (4 разряда) и двоичном (8 разрядов) виде.

> [!success]- Решение
> ```csharp
> Console.WriteLine($"{255:X4}");   // 00FF
> Console.WriteLine($"{255:b8}");   // 11111111  (формат "b" — .NET 8+)
> ```

### 3.7. Сборка строки в цикле
Собери отчёт из 100 000 строк. Покажи разницу подходов.

> [!success]- Решение
> ```csharp
> var sb = new System.Text.StringBuilder(lines.Count * 32);
> foreach (var line in lines) sb.Append(line).Append('\n');
> var report = sb.ToString();
> ```
> `report += line` дал бы `O(n²)` по копированию. Если строки уже в коллекции, ещё проще: `string.Join('\n', lines)`.

### 3.8. Raw string
Запиши JSON-шаблон с кавычками и подстановкой без экранирования.

> [!success]- Решение
> ```csharp
> var name = "Иван";
> var json = $$"""
>     {"name": "{{name}}", "active": true}
>     """;
> ```
> Двойные `$$` означают, что выражение начинается с двух фигурных скобок — удобно для JSON.

## 4. Массивы: основы

### 4.1. Развернуть на месте
Разверни массив без второго массива.

> [!success]- Решение
> ```csharp
> for (int i = 0, j = a.Length - 1; i < j; i++, j--)
>     (a[i], a[j]) = (a[j], a[i]);
> ```
> `O(n)` времени, `O(1)` памяти.

### 4.2. Второй максимум
Найди второе по величине **различное** значение за один проход.

> [!success]- Решение
> ```csharp
> long max = long.MinValue, second = long.MinValue;
> foreach (var x in data)
> {
>     if (x > max) { second = max; max = x; }
>     else if (x > second && x != max) second = x;
> }
> ```
> Один проход вместо сортировки; `long` в накопителях избавляет от флагов «ещё не найдено».

### 4.3. Дубликаты
Найди все повторяющиеся элементы массива.

> [!success]- Решение
> ```csharp
> var seen = new HashSet<int>();
> var duplicates = data.Where(x => !seen.Add(x)).Distinct().ToArray();
> ```
> `Add` возвращает `false`, если элемент уже был. `O(n)` времени и памяти против `O(n²)` у двойного цикла.

### 4.4. Слияние отсортированных
Слей два отсортированных массива в один отсортированный.

> [!success]- Решение
> ```csharp
> static int[] Merge(int[] a, int[] b)
> {
>     var result = new int[a.Length + b.Length];
>     int i = 0, j = 0, k = 0;
>     while (i < a.Length && j < b.Length) result[k++] = a[i] <= b[j] ? a[i++] : b[j++];
>     while (i < a.Length) result[k++] = a[i++];
>     while (j < b.Length) result[k++] = b[j++];
>     return result;
> }
> ```
> `O(n + m)`. Сортировка объединения дала бы `O((n+m) log(n+m))`.

### 4.5. Бинарный поиск
Реализуй бинарный поиск вручную, без переполнения при вычислении середины.

> [!success]- Решение
> ```csharp
> static int BinarySearch(int[] sorted, int target)
> {
>     int lo = 0, hi = sorted.Length - 1;
>     while (lo <= hi)
>     {
>         int mid = lo + (hi - lo) / 2;          // не (lo + hi) / 2 — переполнение
>         if (sorted[mid] == target) return mid;
>         if (sorted[mid] < target) lo = mid + 1; else hi = mid - 1;
>     }
>     return -1;
> }
> ```
> `O(log n)`; работает только на отсортированном массиве.

### 4.6. Сдвиг массива
Сдвинь элементы циклически вправо на k позиций за `O(1)` дополнительной памяти.

> [!success]- Решение
> ```csharp
> static void Rotate(int[] a, int k)
> {
>     k = ((k % a.Length) + a.Length) % a.Length;
>     Array.Reverse(a);
>     Array.Reverse(a, 0, k);
>     Array.Reverse(a, k, a.Length - k);
> }
> ```
> Трюк «тройного разворота»: три разворота дают циклический сдвиг без дополнительного массива.

### 4.7. Ступенчатый и многомерный
В чём разница между `int[3,4]` и `int[3][]`? Создай оба и заполни.

> [!success]- Решение
> ```csharp
> var rect = new int[3, 4];                     // один объект, все строки равной длины
> var jagged = new int[3][];                     // массив ссылок
> for (int i = 0; i < 3; i++) jagged[i] = new int[i + 1];   // строки разной длины
> Console.WriteLine(rect.Length);                // 12 — ВСЕГО элементов
> Console.WriteLine(rect.GetLength(0));          // 3
> ```

### 4.8. Ковариантность
Почему `object[] arr = new string[1]; arr[0] = 42;` компилируется, но падает?

> [!success]- Решение
> Массивы ссылочных типов ковариантны — наследие C# 1.0. Проверка типа выполняется в рантайме при записи: `ArrayTypeMismatchException`. Безопасная альтернатива для чтения — `IReadOnlyList<T>`.

## 5. Алгоритмы и производительность

### 5.1. Два числа с заданной суммой
Найди индексы двух элементов, дающих в сумме target, за один проход.

> [!success]- Решение
> ```csharp
> static (int, int)? TwoSum(int[] a, int target)
> {
>     var seen = new Dictionary<int, int>();
>     for (int i = 0; i < a.Length; i++)
>     {
>         if (seen.TryGetValue(target - a[i], out var j)) return (j, i);
>         seen[a[i]] = i;
>     }
>     return null;
> }
> ```
> `O(n)` вместо `O(n²)`: словарь «значение → индекс» вместо вложенного цикла.

### 5.2. Максимальная сумма подмассива
Найди максимальную сумму непрерывного подмассива (алгоритм Кадане).

> [!success]- Решение
> ```csharp
> static int MaxSubarray(int[] a)
> {
>     int best = a[0], current = a[0];
>     for (int i = 1; i < a.Length; i++)
>     {
>         current = Math.Max(a[i], current + a[i]);
>         best = Math.Max(best, current);
>     }
>     return best;
> }
> ```
> `O(n)`: на каждом шаге решаем, продолжать текущий подмассив или начать новый.

### 5.3. Скользящее окно
Найди максимальную сумму k подряд идущих элементов.

> [!success]- Решение
> ```csharp
> static int MaxWindow(int[] a, int k)
> {
>     int sum = 0;
>     for (int i = 0; i < k; i++) sum += a[i];
>     int best = sum;
>     for (int i = k; i < a.Length; i++)
>     {
>         sum += a[i] - a[i - k];        // добавили новый, убрали выбывший
>         best = Math.Max(best, sum);
>     }
>     return best;
> }
> ```
> `O(n)` вместо `O(n·k)` при пересчёте суммы окна каждый раз.

### 5.4. Частотный словарь
Найди самое частое слово в тексте.

> [!success]- Решение
> ```csharp
> var top = text.Split((char[]?)null, StringSplitOptions.RemoveEmptyEntries)
>     .GroupBy(w => w, StringComparer.OrdinalIgnoreCase)
>     .MaxBy(g => g.Count());
> ```
> `MaxBy` (.NET 6+) избавляет от `OrderByDescending().First()`, который сортировал бы всё.

### 5.5. Убрать квадратичность
Ускорь поиск заказов, содержащих запрещённые товары (списки по 10 000 и 3 000).

> [!success]- Решение
> ```csharp
> var blocked = new HashSet<int>(blockedIds);                 // O(m), один раз
> var result = orders.Where(o => o.Items.Any(i => blocked.Contains(i.ProductId))).ToList();
> ```
> Было `O(n·k·m)` из-за `List.Contains` внутри цикла, стало `O(n·k)`. Ключевое — построить множество **до** цикла.

### 5.6. Срез без копирования
Передай часть массива в метод, не создавая новый массив.

> [!success]- Решение
> ```csharp
> static int Sum(ReadOnlySpan<int> part) { int s = 0; foreach (var x in part) s += x; return s; }
> Sum(data.AsSpan(10, 100));       // окно в тот же массив
> // data[10..110] создало бы копию
> ```

### 5.7. Пул буферов
Прочитай данные в буфер на 64 КБ, не создавая мусор при каждом вызове.

> [!success]- Решение
> ```csharp
> var pool = System.Buffers.ArrayPool<byte>.Shared;
> byte[] buffer = pool.Rent(64 * 1024);
> try { /* работать с buffer.AsSpan(0, 64 * 1024) */ }
> finally { pool.Return(buffer); }
> ```
> `Rent` может вернуть массив **больше** запрошенного — полагаться надо на запрошенную длину, а не на `buffer.Length`.

### 5.8. Оценить сложность
Алгоритм `O(n²)` обрабатывает 1000 элементов за секунду. Сколько займут 100 000 и что делать?

> [!success]- Решение
> Рост данных в 100 раз даёт рост времени в 10 000 раз: примерно 10 000 секунд, около трёх часов. Ускорение констант не спасёт — нужно менять асимптотику: индекс (`Dictionary`/`HashSet`) вместо вложенного поиска, предварительная сортировка с двумя указателями или группировка одним проходом. `O(n log n)` на 100 000 — это порядка 1,7 млн операций, единицы миллисекунд.
