## Целевые версии — сверяться при дописывании

| Что | Версия | Примечание |
|---|---|---|
| .NET | **10.0 LTS** | релиз 11.11.2025, поддержка до 10.11.2028 — целевая |
| C# | **14** | `field`, extension members, `?.=`, partial ctors |
| EF Core | **10** | complex types в JSON, именованные фильтры, LeftJoin |
| ASP.NET Core | **10** | OpenAPI 3.1, валидация Minimal API, SSE, passkeys |
| .NET 9 | EOL 12.05.2026 | не рекомендовать |
| .NET 11 / C# 15 | релиз 10.11.2026 | union-типы, Runtime Async — только как «что впереди» |

Отдельно проверять при дописывании (лицензии изменились в 2025–2026 и это влияет на рекомендации):
- **MediatR** — платный для организаций с v13
- **FluentAssertions** — платный для коммерции с v8 → рекомендовать Shouldly
- **MassTransit** — v9 коммерческая, v8 бесплатна
- **Moq** — репутационные проблемы после SponsorLink → рекомендовать NSubstitute

Как проверять актуальность самому — [[Как поддерживать базу в актуальном состоянии]].
